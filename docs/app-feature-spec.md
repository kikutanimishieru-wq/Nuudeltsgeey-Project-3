# App Feature Specification — Competition Addendum v1

This addendum covers new requirements; it is not a replacement for the full product specification.

## Tournament style selector

See the [operations manual](./tournament-operations.md) for all eight styles and fields. Hosts configure style and eligibility policy, never opponents. Planned Generate Bracket action uses verified entrants and offers no manual seed editing, dragging, targeting, or reroll.

Current UI stores configuration locally; bracket execution remains pending. Existing events without style metadata continue to display normally.

## Arena Days experience

Separate continuous Daily Arena events from designated National Arena Days. Until a real event is announced, show an honest empty state. After announcement, show the countdown and qualification period. Profile qualification must come from verified eligibility, never a self-assigned badge. Major event publication must validate a designated Arena Day and invitation/qualification requirements.

The [Ikh Zasag Rulebook](./ikh-zasag-rulebook.md) is the canonical source of the new fairness and Arena Day rules.
